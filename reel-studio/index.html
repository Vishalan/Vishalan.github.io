How it works

  1. Drop the folder in

    Unzip Reel Studio and open it in your agent. One setup command checks Node, Chrome and ffmpeg and tells you what is missing.

  2. Type one line

    The agent picks the angle, writes the script for the ear, records the voice and builds the scenes.

  3. Get the MP4

    Every frame is checked for text running off the edge or under the app buttons, then ffmpeg renders the final file.

What it does for you

Script

A topic judge picks an angle worth watching. The script is written to be spoken: short lines, numbers said the way people say them, a hook in the first second.

Voice

Free local voices that run on your machine. If you have an ElevenLabs key, it uses that instead. Either way, captions are timed to the words.

Scenes

Every frame is drawn in code: animated app mockups, counters, stamps, charts and a print style halftone look. No stock footage and no AI images.

Sound

Whooshes, ticks and stamps land on the frame they belong to, not just somewhere near it. The timing guide explains why each one goes where it does.

Frame judge

Before the render, it checks each frame for text that is clipped, overlapping, or hidden behind the like and comment buttons, and fixes the layout.

Any niche

Finance, science, history, cooking, your own product. Narration is in English today; other languages are on the list for an update.

Questions

What if it is not for me?

Refunds follow Gumroad's standard refund policy. If something does not work on your machine, email me first and I will help you get it running.

Does it work on Windows?

It is built to: the tools it uses (Node, Chrome, ffmpeg) all run on Windows, and the setup guide covers installing them. It was built and tested on a Mac, so if anything trips on Windows, email me and I will fix it in an update.

Do I need to know how to code?

No. You type in plain English to your agent. You do need to be comfortable running a terminal command or two during setup.

Is the voice really free?

Yes. The default voices run locally on your computer with no account and no per minute cost. ElevenLabs is there if you already pay for it.

Can I sell or monetise the videos I make?

Yes. The videos are yours, including client work. The bundled sounds are CC0 and the fonts are OFL, so nothing in the output needs credit. The skill itself is licensed to you personally: please do not share or resell the folder.

Which AI agent should I use?

Any of Claude Code, Claude Desktop, Codex, Antigravity or Cursor. The skill is written so each of them can follow it. The agent's own plan or subscription is separate from Reel Studio.
